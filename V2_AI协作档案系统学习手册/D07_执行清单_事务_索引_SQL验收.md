# D07 今天照做执行清单：事务、索引与 SQL 验收

## 上午：设计事务（09:00–12:00）

1. [ ] 新建 `D07-notes.md`，写标题：`批准借阅事务`、`回滚断言`、`索引`、`SQL 自测`。
2. [ ] 在纸上画三步：申请状态更新 → 借阅记录新增 → 档案状态更新。
3. [ ] 为每一步写“成功后值”和“任一步失败时应保持的旧值”。
4. [ ] 向 AI 发送三步和状态，要求只输出事务伪代码、失败场景和回滚断言。

## 下午：在学习库演示（15:00–18:00）

1. [ ] 执行 `SELECT DATABASE();`，确认学习库。
2. [ ] 用 DBeaver **SQL Editor → New SQL Script** 建最小申请/借阅记录测试数据；先执行 SELECT 确认初始状态。
3. [ ] 输入 `START TRANSACTION;`，逐条执行三步更新/插入，分别查询结果。
4. [ ] 输入 `COMMIT;`；再次 SELECT，截图成功状态。
5. [ ] 重置测试数据后再次 `START TRANSACTION;`；故意执行一条会失败的 SQL（例如不存在的关联 ID），看到错误后输入 `ROLLBACK;`。
6. [ ] SELECT 三张表，确认无半成品；在笔记写“回滚证明”。

## 晚上：索引和自测（19:00–23:00）

1. [ ] 为 `archive_no`、分类关联、状态/到期日写候选索引清单及查询目的。
2. [ ] 让 AI 生成 `CREATE INDEX` 草案；人工确认不重复主键/唯一索引。
3. [ ] 在学习库逐条执行，使用 `SHOW INDEX FROM 表名;` 核对。
4. [ ] 不查资料完成：一条 DDL、一条 INSERT、一条 LIKE、一条 JOIN、一条 GROUP BY、一次事务；标注不会的项。
