## 📌 一、**完全后台运行**以后怎么管理 Redis 服务？

| 操作          | 命令（管理员 CMD）                        |
| ----------- | ---------------------------------- |
| 启动 Redis    | `net start Redis`                  |
| 停止 Redis    | `net stop Redis`                   |
| 卸载 Redis 服务 | `redis-server --service-uninstall` |
