# JDK、JVM 与若依项目运行原理

> [!NOTE] 核心定义
> **JDK = JVM + 编译器（javac）+ 开发工具（jar、javadoc）+ 核心类库（String、ArrayList、HashMap 等）**。
> 
> JVM 的**跨平台能力**是 Java 最核心的优势：你在 Windows 上写的代码，编译成 `.class` 文件后，放到 Linux 或 Mac 上，只要装了对应版本的 JVM，就能**直接运行**，无需修改代码。

## 🚀 一、JDK 在若依后端项目中的具体作用

若依后端是一个 **Spring Boot 项目**，其完整的生命周期依赖于 JDK 的不同组件。

### 阶段一：开发时（IDEA 中编写代码）

| 步骤 | 执行者 | 具体动作 |
| :--- | :--- | :--- |
| **编写代码** | 你 | 在 IDEA 中创建并编辑 `.java` 源文件。 |
| **实时编译** | **JDK 中的 `javac`** | 保存文件时，IDEA 调用 JDK 编译器，将 `.java` 翻译成 `.class`（字节码）。 |
| **代码提示** | **JDK 核心类库** | 输入 `String.` 时，IDEA 基于 JDK 类库索引提示可用方法。 |
| **项目构建** | **JDK** | 执行 `mvn package`，Maven 调用 JDK 编译全项目，生成可执行的 `ruoyi-admin.jar`。 |

### 阶段二：运行时（项目启动后）

| 步骤 | 执行者 | 具体动作 |
| :--- | :--- | :--- |
| **启动项目** | **JVM** | 执行 `java -jar ruoyi-admin.jar`，**JVM 加载 `.class` 文件并开始执行**。 |
| **处理请求** | **JVM** | 用户访问页面时，后端 Controller/Service 在 **JVM 内执行**，查询数据库并返回 JSON。 |
| **内存管理** | **JVM** | JVM 自动分配内存，并通过**垃圾回收（GC）**回收无用对象，无需手动释放。 |
| **并发处理** | **JVM** | 若依同时处理多用户请求，JVM 负责线程调度与上下文切换。 |

## 🎯 二、IDEA / JDK / JVM 的关系总结

> [!TIP] 三者定位
> - **IDEA** 是“工作台”，负责让你方便地写代码、点按钮。
> - **JDK** 是“工具箱”，提供编译、打包、运行所需的全套工具。
> - **JVM** 是“发动机”，真正负责执行 Java 程序的引擎。

| 工具       | 角色定位               | 本地安装路径示例                                 |
| :------- | :----------------- | :--------------------------------------- |
| **IDEA** | 集成开发环境（编辑器 + 构建工具） | `C:\devTool\Intellij IDEA`               |
| **JDK**  | 编译工具 + 运行环境 + 核心类库 | `C:\devTool\JDK11`                       |
| **JVM**  | Java 程序的执行引擎       | **包含在 JDK 中**（位于 `bin` 目录下，如 `java.exe`） |

---

> [!EXAMPLE] 若依启动流程速记
> 1. 你在 IDEA 点击启动（本质是调用 JDK）。
> 2. JDK 启动 JVM。
> 3. JVM 加载若依的 `.jar` 包。
> 4. Spring Boot 在 JVM 内启动，监听 8080 端口。
> 5. 用户请求进来，JVM 分配线程执行你的业务代码。
