# 若依图书管理系统 · 全栈核心概念速查

> [!TIP] 阅读指南
> 本文档梳理了基于若依框架的图书管理系统所涉及的全栈技术概念，分为**后端基石**、**前端生态**、**架构与规范**及**开发工具**四类。适合零基础开发者作为案头速查手册。

## 🎯 一、核心概念分类速查

### 1. 后端基石（Java 生态）
- **JDK (Java Development Kit)**：Java 程序的编译与运行环境，包含 JVM、编译器（javac）和核心类库，是后端开发的基石。
- **JVM (Java Virtual Machine)**：JDK 中的执行引擎，负责将字节码翻译为机器指令，提供跨平台能力和自动内存管理（GC）。
- **Spring Boot**：Java 后端开发框架，简化配置，通过“自动配置”机制，若依框架基于此构建。
- **MyBatis**：数据访问框架（ORM），负责将 Java 对象映射为 SQL 语句，与 MySQL 交互。
- **Tomcat**：Java Web 服务器（若依已内嵌），负责接收 HTTP 请求并交给后端处理，默认监听 8080 端口。

### 2. 数据存储与缓存
- **MySQL**：关系型数据库，持久化存储图书信息、借阅记录、用户权限等核心业务数据。
- **Redis**：内存缓存数据库，用于存储登录态、验证码等高频访问数据，显著提升系统响应速度。
- **JWT (JSON Web Token)**：若依使用的用户身份验证机制，登录后生成加密令牌，后续请求通过校验令牌确认用户身份。

### 3. 前端生态（Vue 生态）
- **Node.js**：JavaScript 运行时环境，让前端构建工具（Vite）和包管理器（npm）能脱离浏览器在本地运行。
- **npm (Node Package Manager)**：Node.js 自带的包管理器，负责下载和管理 `node_modules` 中的前端依赖。
- **Vue 3**：前端 UI 框架，采用组件化开发模式，用于构建若依项目的用户界面。
- **Vite**：前端构建工具，提供开发时热更新（`npm run dev`）和生产环境代码打包能力。
- **Element Plus**：基于 Vue 3 的 UI 组件库，提供表格、按钮、弹窗等开箱即用的组件，若依前端基于此美化。
- **Axios**：前端 HTTP 客户端，负责封装请求、携带 Token、向后端 API 发送请求并获取数据。

### 4. 架构与规范
- **若依 (RuoYi)**：基于 Spring Boot + Vue 的快速开发框架，提供用户/角色/菜单权限、代码生成器等基础能力，是本项目的骨架。
- **前后端分离**：前端（Vue）和后端（Java）独立开发、独立部署，通过 JSON 格式的 API 接口通信。
- **RESTful**：API 设计风格，通过 HTTP 方法（GET/POST/PUT/DELETE）表达“增删改查”的语义。
- **CRUD**：即增删改查（Create, Read, Update, Delete），是图书管理系统的核心功能组合。

### 5. 开发工具与依赖管理
- **Maven**：后端依赖管理工具，通过 `pom.xml` 定义坐标，自动下载 jar 包并构建项目。
- **Maven 本地仓库**：Maven 下载 jar 包后的本地缓存目录（通常位于 `C:\Users\用户名\.m2`）。
- **node_modules**：npm 下载前端依赖后的存放目录，位于项目根目录下。
- **Git**：分布式版本控制系统，用于拉取若依源码、记录代码变更及团队协作。
- **IDE (集成开发环境)**：如 IntelliJ IDEA，集成了代码编辑、编译、调试、版本控制等全套工具。

## 🔄 二、系统请求处理流程

> [!EXAMPLE] 数据流动全景图
> 以下流程图展示了从用户操作到数据持久化的完整闭环（以“查询图书”为例）：
> 
> ```mermaid
> flowchart LR
>     A[前端 Vue 3<br>用户点击查询] -- HTTP 请求 / Axios --> B{后端 Spring Boot}
>     B -- 权限校验 / JWT --> B
>     B -- 业务逻辑 --> C[MyBatis]
>     C -- SQL 操作 --> D[(MySQL<br>图书表)]
>     C -- 缓存读写 --> E[(Redis<br>热点数据)]
>     B -- JSON 数据 --> A
> ```

> **一句话总结**：用户在前端操作 → Axios 发送请求 → 后端处理业务（Spring Boot + MyBatis）→ 读写数据库或缓存 → 返回 JSON → 前端渲染视图。所有代码通过 Git 管理，依赖分别由 Maven 和 npm 自动处理。🚀

## 🧠 三、给零基础的学习与开发顺序

> [!NOTE] 建议路径
> 不要试图一次性理解所有名词，按照以下步骤逐步推进：

1. **环境搭建**：安装 JDK、Node.js、MySQL、Redis，使用 `mvn package` 和 `npm run dev` 成功启动若依。
2. **代码生成**：利用若依自带的代码生成器，导入图书表，生成前后端基础 CRUD 代码。
3. **前端微调**：在 `ruoyi-ui/src/views` 下找到生成的页面，修改表格字段和文案。
4. **后端加料**：在 `ruoyi-system` 模块的 Service 层添加业务逻辑（如“库存低于 5 本预警”）。
5. **流程串联**：通过 Debug 模式，跟踪一次 HTTP 请求是如何从 Controller 走到 Mapper 的。
