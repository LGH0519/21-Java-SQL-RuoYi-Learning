# 每日学习执行单：使用说明

本目录中的 `D01` 到 `D20` 是每天独立使用的一张训练单。每天只打开当天文件，按时间块完成；不要提前观看后面课程。

## 每天的使用顺序

1. 09:00 打开当天文档，勾选“开始前检查”。
2. 只看文档规定的视频标题/文档章节，视频播放速度最多 1.25 倍。
3. 每看 20–30 分钟，暂停并完成对应的小操作；不能只看视频。
4. 依据“验收”截图、保存 SQL 或运行接口；将证据放在仓库 `docs/day-xx/`。
5. 19:00 后使用 `00_工具安装与调试手册.md` 的流程，对当天最重要的一条代码或接口做一次调试。
6. 完成两次 Git 提交后，才算当天结束。

## 文件索引

- `00_工具安装与调试手册.md`：工具用途、安装顺序、Java/前端/SQL 调试流程。
- `00_每日学习执行单模板.md`：当天卡住、请 AI 帮忙、提交、复盘的填写模板。
- `D01`–`D20`：逐日计划。

## 判断是否进入下一天

当天“必须验收”未达成时，最多把 90 分钟挪到次日晚上补齐；若仍没完成，立即删除可选项，不能因此推迟主项目核心功能。

## 目录建议

在两个项目仓库中统一建：

```text
docs/
  day-01/      # 截图、SQL、接口响应、当天笔记
  design/      # 需求、ER 图、状态图
  api/         # Apifox/Postman 导出或截图
sql/           # 可重复执行的建表和初始化数据脚本
```
