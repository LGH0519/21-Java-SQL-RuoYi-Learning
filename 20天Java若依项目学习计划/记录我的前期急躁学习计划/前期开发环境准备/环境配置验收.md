## 📌 二、关键易疏漏点整理（文档中重点标注）

|易疏漏点|正确做法|错误后果|
|---|---|---|
|**MySQL 数据目录**|必须放在 **C 盘（SSD）**，如 `C:\mysql-data`|放在 D 盘机械硬盘，启动慢 3-5 倍|
|**Maven 本地仓库**|必须改到 **D 盘**，如 `D:\maven-repository`|默认在 C 盘，会膨胀到 1-2GB|
|**npm 缓存**|必须改到 **D 盘**，`npm config set cache D:\npm-cache`|默认在 C 盘用户目录，占用系统盘空间|
|**环境变量 PATH**|安装 Git、MySQL、Redis 后都要检查 `PATH` 是否添加了对应的 `bin` 目录|无法在任意目录下执行命令|
|**MySQL 远程访问**|执行 `UPDATE user SET Host = '%' WHERE User = 'root';`|无法用 DBeaver 等工具远程连接|
|**Redis 服务**|建议安装为 Windows 服务，开机自启|每次开机需手动双击 `redis-server.exe`|
|**IDEA 激活**|选择“30天试用”或“免费非商用使用”|—|

## 🆚 三、RuoYi-Vue vs RuoYi-Vue3 区别

| 对比维度      | **RuoYi-Vue**                  | **RuoYi-Vue3**           |
| --------- | ------------------------------ | ------------------------ |
| **是什么**   | 若依**后端**代码（Java + Spring Boot） | 若依**前端**代码（Vue 3）        |
| **技术栈**   | Java、Spring Boot、MyBatis       | Vue 3、Vite、Element Plus  |
| **运行方式**  | 在 IDEA 中运行 Spring Boot 项目      | 在 CMD 中执行 `npm run dev`  |
| **默认端口**  | **8080**（后端 API 接口）            | **80**（前端页面）             |
| **主要文件**  | `pom.xml`（Maven 配置文件）          | `package.json`（npm 配置文件） |
| **数据库相关** | 有 `sql` 文件夹，存放建表语句             | 没有数据库相关文件                |
