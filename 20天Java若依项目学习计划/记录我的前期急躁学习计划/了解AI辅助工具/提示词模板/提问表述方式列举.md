# 二、解析文件内容

- 请详细解释该文件，每行或者每段或者每部分的具体功能，以及在实际开发中的应用。
- 以后解释技术内容时，做到：每个专有名词首次出现时都给出通俗解释，而不是假设读者已经知道。
- 用生活中的类比帮助理解抽象概念。

# 四、问答式发布任务

我想让你帮我我制作一份可量化的详细学习计划或者规划。你有什么想了解的可以直接问我，采用一问一答的方式，同时说清楚你为什么要问这个问题，直到你对我的情况有了明确的认知，再开始制作计划。

- 原则三：精准修改 (Surgical Changes)
