涉及的知识点：
1、IDEA中Tab键自动补全后续整段提示代码。
2、psvm自动补全public static void main(String[] args) {}，启动入口。
3、关键字super：代表对象的父类引用，还想调用父类的原始实现时使用。super.test()就是通过这个父类引用，调用父类中定义的test()方法。
4、一般一个public定义的类占一个.java文件，文件名必须与 `public` 类名完全一致（包括大小写）。
5、多态：变量可以声明为某个类的父类类型，但实际创建该类的子类对象。父类类型的变量，可以指向子类的对象。
6、@Override注解：表示该方法是对父类（或接口）中同名方法的重写，而不是定义了一个新方法，并让编译器帮忙检查方法名和签名是否正确。
7、关键字extends：表示"继承自"，让子类自动拥有父类的功能，并可以在父类基础上进行扩展或修改，实现代码复用和多态。
8、继承的特性：单继承（Java 中一个类只能 extends 一个父类）、传递性（`A extends B`，`B extends C` → `A` 间接继承 `C`）、不能继承（`private` 成员、构造器（但可以通过 `super()` 调用））、所有类都继承Object（如果没有写 `extends`，默认继承 `java.lang.Object`）。
9、可以把“包”理解成存放 Java 类的文件夹，同时也用于区分重名的类。
