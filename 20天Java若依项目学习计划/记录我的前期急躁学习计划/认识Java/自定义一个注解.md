# **注解的列举及解释**

如：自定开发一个Web容器，基本功能是加载Servlet，需要管理它的生命周期，所有必须先识别程序中的哪些类是Servlet。
程序启动的时候，扫描所有的类，找出添加了@WebServlet注解的类，进行加载。
@WebServlet是在程序运行的时候起作用的，Java就把它的作用范围规定为RUNTIME。

@Override是编译时候起作用，Java就把它的作用范围规定为SOURCE。

# 元注解
## @Target指定注解针对的地方

ElementType:
ElememtType.TYPE                           针对类、接口
ElememtType.FIELD                          针对成员变量
ElememtType.METHOD                    针对成员方法
ElememtType.PARAMETER               针对方法参数
ElememtType.CONSTRUCTOR          针对构造器
ElememtType.PACKAGE                    针对包
ElememtType.ANNOTATION_TYPE   针对注解

## @Retention指定注解的保留域

RetentionPolicy：
RetentionPolicy.SOURCE     源代码级别，由编译器处理，处理之后就不再保留
RetentionPolicy.CALSS        注解信息保留到类对应的class文件中
RetentionPolicy.RUNTIME   由JVM读取，运行时使用

# 自定义一个注解

## 定义 `@InitMethod` 注解
```
package com.southwind.com.southwind.test3;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface InitMethod {
}
```
注解本身仅仅只是一个标注，它本身并不具备具体逻辑处理的功能。后续要搭配反射发挥作用。（注解本身不会执行方法。它只相当于一个“标签”；真正识别标签并执行方法的是后续的反射代码。）
## 给方法贴上注解
```
package com.southwind.com.southwind.test3;

public class InitDemo {

    @InitMethod
    public void init() {
        System.out.println("init...");
    }

    @InitMethod
    public void test() {
        System.out.println("test...");
    }
}
```
## 找到并执行被标记的方法
```
package com.southwind.com.southwind.test3;

import java.lang.reflect.Method; /*引入Java反射系统中的Method类*/

public class Test {

    public static void main(String[] args) throws Exception {

        Class clazz = Class.forName(
            "com.southwind.com.southwind.test3.InitDemo"
        );  /*请根据这串文字找到对应的类，把这个类的完整资料交给我*/

        Method[] methods = clazz.getMethods(); /*获取这个类中能够访问到的所有公开方                         法，每个方法都用一个Method对象表示，最后放进数组methods中*/

        if (methods != null) {
            for (Method method : methods) { /*把methods数组里的方法逐个拿出来检                                     查，每次循环，当前被检查的方法保存在变量method中*/
                boolean isInitMethod =
                    method.isAnnotationPresent(InitMethod.class);
                    /*当前方法上有没有@InitMethod注解？*/
                    /*InitMethod.class表示InitMethod这个注解的类型信息*/

                if (isInitMethod) {
                    Object object = clazz.getConstructor().newInstance();
	                method.invoke(object);
                }
            }
        }
    }
}
```
定义测试程序。它负责扫描 `InitDemo`，找出带注解的方法，然后执行。
类的完整名字由“包名 + 类名”构成。
```
Object object = clazz.getConstructor().newInstance();
```
`clazz.getConstructor()`获取`InitDemo`这个类的公开无参数构造方法。
`.newInstance()`调用`InitDemo`类中的构造方法，创建一个 `InitDemo` 对象。

```
method.invoke(object);   /*在刚刚创建的对象上执行当前方法*/
						/*反射的invoke()可以理解成“调用”或“执行”*/
```
如果当前 `method` 表示 `init()`，它大致相当于：
```
object.init();
```
如果当前 `method` 表示 `test()`，它大致相当于：
```
object.test();
```
