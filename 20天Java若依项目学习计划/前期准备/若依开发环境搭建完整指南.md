# 若依（RuoYi-Vue）开发环境搭建完整指南

> 本文档适用于 Windows 10/11 系统，从零开始搭建基于 JDK 17 + Spring Boot 3.x + Vue 3 的若依前后端分离开发环境。


## 一、硬件环境要求

| 项目 | 最低要求 | 推荐配置 |
|:---|:---|:---|
| 操作系统 | Windows 10 1809+ | Windows 11 |
| 内存 | 8 GB | 16 GB+ |
| 硬盘 | 固态硬盘（SSD），剩余空间 50 GB+ | 固态硬盘，剩余空间 100 GB+ |
| CPU | 4 核 | 8 核+ |

> ⚠️ **核心原则**：程序本体放 **C 盘（SSD）**，数据/缓存/项目代码放 **D 盘（HDD）**，以保护系统盘空间。

## 三、工具安装与配置详解

### 3.1 JDK 17

**安装路径**：`C:\devTool\JDK17`

**环境变量配置**：
| 变量名 | 变量值 |
|:---|:---|
| `JAVA_HOME` | `C:\devTool\JDK17` |
| `PATH` | 添加 `%JAVA_HOME%\bin` |

**验证**：
```cmd
java -version
# 应显示 openjdk version "17.0.x"
```

> 💡 **注意**：若依 3.x 分支要求 JDK 17+。JDK 11 和 JDK 17 可以共存，在 IDEA 中为不同项目单独指定 JDK 版本。


### 3.2 Maven

**安装路径**：`D:\devTool\apache-maven-3.9.16`

**本地仓库路径**：`D:\maven-repository`

**环境变量配置**：
| 变量名 | 变量值 |
|:---|:---|
| `MAVEN_HOME` | `D:\devTool\apache-maven-3.9.16` |
| `PATH` | 添加 `%MAVEN_HOME%\bin` |

**配置文件修改**（`D:\devTool\apache-maven-3.9.16\conf\settings.xml`）：

1. 修改本地仓库位置：
```xml
<localRepository>D:/maven-repository</localRepository>
```

2. 添加阿里云镜像（加速依赖下载）：
```xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

**验证**：
```cmd
mvn -version
# 应显示 Apache Maven 3.9.x 和 Java version: 17.0.x
```


### 3.3 Git

**安装路径**：`D:\devTool\Git`

**安装注意事项**：
- 默认分支名选择：**"Override the default branch name for new repositories"**，填写 `main`
- HTTPS 传输后端：选择 **"Use the native Windows Secure Channel library"**

**初始配置**：
```cmd
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global --list  # 验证配置
```


### 3.4 Node.js

**安装路径**：`C:\Program Files\nodejs`（保持默认）

**版本要求**：18.x LTS（若依 Vue3 前端要求 Node.js 18+）

**配置 npm 缓存到 D 盘**：
```cmd
npm config set cache D:\npm-cache
npm config set registry https://registry.npmmirror.com  # 配置淘宝镜像
```

**验证**：
```cmd
node -v   # 应显示 v18.x.x
npm -v    # 应显示 10.x.x
```


### 3.5 MySQL 8.0

**程序安装路径**：`D:\devTool\mysql-8.0.46`

**数据目录路径**：`C:\mysql-data`（⚠️ 必须放在 SSD，保证读写性能）

**安装方式**：ZIP 绿色版（手动配置）

**配置文件**（`D:\devTool\mysql-8.0.46\my.ini`）：
```ini
[mysqld]
basedir = D:/devTool/mysql-8.0.46
datadir = C:/mysql-data
port = 3306
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
max_connections = 200
default-storage-engine = INNODB

[client]
port = 3306
default-character-set = utf8mb4
```

**初始化与启动**（管理员 CMD）：
```cmd
# 进入 bin 目录
D:
cd D:\devTool\mysql-8.0.46\bin

# 初始化数据库（记下临时密码）
mysqld --initialize --console

# 安装为 Windows 服务
mysqld --install MySQL

# 启动服务
net start MySQL

# 登录并修改密码
mysql -u root -p
ALTER USER 'root'@'localhost' IDENTIFIED BY 'root123';
FLUSH PRIVILEGES;
exit;
```

**开启远程访问**：
```sql
USE mysql;
UPDATE user SET Host = '%' WHERE User = 'root' AND Host = 'localhost';
FLUSH PRIVILEGES;
```

**环境变量配置**：将 `D:\devTool\mysql-8.0.46\bin` 添加到系统 `PATH` 中。


### 3.6 Redis

## 四、若依项目源码拉取与初始化

### 4.1 拉取源码

```bash
# 创建项目目录
D:
mkdir projects
cd projects

# 克隆若依后端（3.x 分支，要求 JDK 17）
git clone https://gitee.com/y_project/RuoYi-Vue.git ruoyi-backend

# 克隆若依前端（Vue 3）
git clone https://gitee.com/ys-gitee/RuoYi-Vue3.git ruoyi-frontend
```

### 4.2 数据库初始化

1. 在 DBeaver 中创建数据库 `ry-vue`，字符集 `utf8mb4`，排序规则 `utf8mb4_general_ci`
2. 依次执行 `ruoyi-backend/sql/` 目录下的 SQL 文件：
   - `ry_2021xxxx.sql`（核心业务表）
   - `quartz.sql`（定时任务表）

### 4.3 修改配置文件

修改 `ruoyi-backend/ruoyi-admin/src/main/resources/application-druid.yml`：
```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
        username: root
        password: root123   # 改为你的 MySQL 密码
```

### 4.4 启动后端

在 IDEA 中打开 `ruoyi-backend` 项目，等待 Maven 依赖下载完成，运行 `RuoYiApplication.java`。

**成功标志**：控制台输出 `(♥◠‿◠) 若依启动成功 ♥`

### 4.5 启动前端

在 VS Code 中打开 `ruoyi-frontend` 项目，执行：
```bash
npm install   # 安装依赖（首次约 3-5 分钟）
npm run dev   # 启动前端
```

**成功标志**：终端显示 `Local: http://localhost:80/`

## 六、常见问题速查

| 问题 | 原因 | 解决方法 |
|:---|:---|:---|
| `'mysql' 不是内部或外部命令` | MySQL 未添加到 PATH | 将 `D:\devTool\mysql-8.0.46\bin` 添加到系统 PATH |
| `Public Key Retrieval is not allowed` | MySQL 8.0 加密方式 | DBeaver 驱动属性设置 `allowPublicKeyRetrieval=true` |
| `无法编译为 JVM 目标 17` | 使用的 JDK 版本低于 17 | 安装 JDK 17，在 IDEA 中为项目指定 JDK 17 |
| `mvn 不是内部或外部命令` | Maven 未添加到 PATH | 配置 `MAVEN_HOME` 和 `PATH` 环境变量 |
| `Redis 连接失败` | Redis 服务未启动 | 执行 `net start Redis` 或双击 `redis-server.exe` |
| `npm install 报错` | 网络问题或权限问题 | 配置淘宝镜像：`npm config set registry https://registry.npmmirror.com` |
| `IDEA 中 Maven 仓库仍在 C 盘` | IDEA 未读取 settings.xml | 在 IDEA 设置中手动指定 User settings file 路径并勾选 Override |
