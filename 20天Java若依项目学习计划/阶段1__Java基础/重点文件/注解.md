# 若依项目注解清单

---

## 一、若依自定义注解（`com.ruoyi.common.annotation` 包）

| 注解              | 作用              | 使用频率 | 典型用法                                                       |
| --------------- | --------------- | ---- | ---------------------------------------------------------- |
| `@Log`          | 记录操作日志          | ⭐⭐⭐  | `@Log(title = "用户管理", businessType = BusinessType.INSERT)` |
| `@Excel`        | 标记 Excel 导出字段   | ⭐⭐⭐  | `@Excel(name = "用户名称")`                                    |
| `@Excels`       | 多个 `@Excel` 的容器 | ⭐⭐   | `@Excels({@Excel(...), @Excel(...)})`                      |
| `@DataScope`    | 数据权限控制          | ⭐⭐   | `@DataScope(deptAlias = "d")`                              |
| `@DataSource`   | 切换数据源           | ⭐⭐   | `@DataSource(value = DataSourceType.SLAVE)`                |
| `@RateLimiter`  | 接口限流            | ⭐    | `@RateLimiter(count = 10)`                                 |
| `@RepeatSubmit` | 防重复提交           | ⭐    | `@RepeatSubmit`                                            |
| `@Anonymous`    | 允许匿名访问          | ⭐    | `@Anonymous`                                               |
| `@Sensitive`    | 数据脱敏            | ⭐    | `@Sensitive(desensitizedType = DesensitizedType.PHONE)`    |

## 二、Spring Boot 核心注解

| 注解 | 作用 | 使用频率 | 典型用法 |
|------|------|---------|---------|
| `@SpringBootApplication` | 启动类标记 | ⭐⭐⭐ | `@SpringBootApplication(exclude = {...})` |
| `@Configuration` | 配置类 | ⭐⭐⭐ | `@Configuration` |
| `@Component` | 通用组件 | ⭐⭐ | `@Component` |
| `@RestController` | REST 控制器 | ⭐⭐⭐ | `@RestController` |
| `@Service` | 业务逻辑类 | ⭐⭐⭐ | `@Service` |
| `@Repository` | 数据访问类 | ⭐ | `@Repository` |
| `@Bean` | 注册 Bean | ⭐⭐⭐ | `@Bean public DataSource ds() {...}` |
| `@Autowired` | 自动注入 | ⭐⭐⭐ | `@Autowired private UserService userService;` |
| `@Resource` | 按名称注入 | ⭐⭐ | `@Resource(name = "captchaProducer")` |
| `@Value` | 注入配置值 | ⭐⭐⭐ | `@Value("${token.secret}")` |
| `@ConditionalOnProperty` | 条件装配 | ⭐ | `@ConditionalOnProperty(name = "xxx", havingValue = "true")` |

## 三、Spring MVC 注解

| 注解                | 作用           | 使用频率 | 典型用法                              |
| ----------------- | ------------ | ---- | --------------------------------- |
| `@RequestMapping` | 映射请求路径       | ⭐⭐⭐  | `@RequestMapping("/system/user")` |
| `@GetMapping`     | 处理 GET 请求    | ⭐⭐⭐  | `@GetMapping("/list")`            |
| `@PostMapping`    | 处理 POST 请求   | ⭐⭐⭐  | `@PostMapping`                    |
| `@PutMapping`     | 处理 PUT 请求    | ⭐⭐   | `@PutMapping`                     |
| `@DeleteMapping`  | 处理 DELETE 请求 | ⭐⭐   | `@DeleteMapping("/{ids}")`        |
| `@PathVariable`   | 获取路径参数       | ⭐⭐⭐  | `@PathVariable Long id`           |
| `@RequestBody`    | 获取请求体        | ⭐⭐⭐  | `@RequestBody SysUser user`       |
| `@RequestParam`   | 获取请求参数       | ⭐⭐   | `@RequestParam String name`       |
| `@ResponseBody`   | 返回 JSON      | ⭐    | 通常包含在 `@RestController` 中         |

## 一句话总结

> 若依项目使用了 **30+ 种注解**，分为 8 大类：若依自定义注解（`@Log`、`@Excel` 等）、Spring Boot 核心注解（`@Autowired`、`@Service` 等）、Spring MVC 注解（`@GetMapping` 等）、Spring Security 注解（`@PreAuthorize`）、AOP 注解（`@Aspect`）、异常处理注解（`@RestControllerAdvice`）、MyBatis 注解（`@Mapper`）、Java 语言级注解（`@Override`）。日常开发中最常用的是 `@Autowired`、`@GetMapping`、`@PreAuthorize`、`@Log` 这四个。
