# 若依项目中常用的 Java 关键字清单

根据项目代码，按**使用频率**和**学习优先级**分为以下几个层次：

---

## 一、最高频 —— 几乎每个文件都会出现

| 关键字 | 作用 | 项目中的例子 | 通俗解释 |
|--------|------|-------------|---------|
| `public` | 公开的，任何地方都能访问 | `public class RuoYiApplication` | "这个类/方法对所有人开放" |
| `class` | 定义一个类 | `public class UserService` | "我要定义一个类型/模板" |
| `import` | 导入其他包中的类 | `import org.springframework.boot.SpringApplication` | "我要用别人写好的工具" |
| `return` | 返回值，结束方法 | `return new MoonCake()` | "把这个结果交出去，方法到此结束" |
| `void` | 表示方法没有返回值 | `public void main(String[] args)` | "这个方法只干活，不交结果" |
| `new` | 创建对象 | `new HashMap<>()` | "照着模具造一个实物" |
| `this` | 指当前对象自己 | `this.mainApplicationClass` | "我自己" |
| `package` | 声明包（代码的"文件夹"） | `package com.ruoyi;` | "这个文件住在哪个地址" |

---

## 二、高频 —— 控制流程，决定代码怎么走

| 关键字 | 作用 | 通俗解释 | 类比 |
|--------|------|---------|------|
| `if` / `else` | 条件判断 | "如果…就…，否则…" | 路口的红绿灯——条件满足走这条路，不满足走那条 |
| `for` | 循环（已知次数） | "重复做 N 次" | 跑圈——说跑 5 圈就跑 5 圈 |
| `while` | 循环（未知次数） | "只要条件满足就一直做" | 吃包子——吃饱了才停，不知道吃几个 |
| `switch` / `case` | 多分支选择 | "根据值选一条路走" | 自动售货机——按 1 出可乐，按 2 出雪碧 |
| `break` | 跳出循环/switch | "不玩了，直接退出" | 吃到第 3 个包子饱了，不吃了 |
| `continue` | 跳过本次循环，进入下一次 | "这个不要，看下一个" | 挑苹果——这个有虫眼，放下看下一个 |

---

## 三、高频 —— 定义变量和修饰符

| 关键字 | 作用 | 通俗解释 | 类比 |
|--------|------|---------|------|
| `int` | 整数类型 | 存整数（1, 2, 3…） | 只能放整数的盒子 |
| `long` | 长整数类型 | 存更大的整数 | 更大的整数盒子 |
| `String` | 字符串类型 | 存文字（"hello"） | 存文字的盒子 |
| `boolean` | 布尔类型 | 只有 `true` 或 `false` | 开关——只有开和关两种状态 |
| `static` | 静态的，属于类而非对象 | "不用造对象就能直接用" | 公共电话——不需要买手机就能打 |
| `final` | 不可修改的 | "一旦赋值就不能改" | 刻在石头上的字——写死了 |
| `private` | 私有的，只有本类能访问 | "这是我的隐私，外人不能碰" | 日记本——只有自己能看到 |
| `protected` | 受保护的，本包 + 子类能访问 | "自家人和亲戚能用" | 家族群——家人和亲戚能看 |
| `default` | 默认值 / 默认访问权限 | "没人填就用这个" | 餐厅的默认套餐——你不点菜就给你上这个 |

---

## 四、中频 —— 面向对象相关

| 关键字 | 作用 | 通俗解释 | 类比 |
|--------|------|---------|------|
| `extends` | 继承父类 | "我是 XX 的升级版" | 儿子继承爸爸的基因 |
| `implements` | 实现接口 | "我承诺做到接口里规定的事" | 签合同——承诺提供某些服务 |
| `interface` | 定义接口 | "一份合同/规范，只规定做什么，不规定怎么做" | 招聘要求——只写"需要会 Java"，不写具体怎么教 |
| `abstract` | 抽象的（类或方法） | "只声明，不实现，让子类去实现" | 老板说"把这个做了"，但不告诉你具体怎么做 |
| `super` | 调用父类的方法/构造器 | "我爸爸的那个方法" | 用爸爸留下的老办法 |
| `override`（`@Override`） | 重写父类方法 | "爸爸的方法我不满意，我自己重新做" | 儿子用新方式做爸爸做过的事 |

---

## 五、中频 —— 异常处理

| 关键字 | 作用 | 通俗解释 | 类比 |
|--------|------|---------|------|
| `try` | 尝试执行可能出错的代码 | "试试做这件事，出错了我兜着" | 走钢丝——下面有安全网 |
| `catch` | 捕获异常 | "出错了怎么办" | 安全网接住掉下来的人 |
| `finally` | 无论是否出错都执行 | "不管成功失败，这件事一定要做" | 下班前一定要关灯——不管今天顺不顺利 |
| `throw` | 主动抛出异常 | "我搞不定，交给上面处理" | 客服解决不了，转给主管 |
| `throws` | 声明方法可能抛出的异常 | "提前声明：我这儿可能出问题" | 警示牌——"前方施工，注意安全" |

---

## 六、中频 —— 其他常用

| 关键字              | 作用           | 通俗解释            |
| ---------------- | ------------ | --------------- |
| `null`           | 空值，表示"什么都没有" | 盒子是空的，里面没东西     |
| `true` / `false` | 布尔值          | 是 / 否           |
| `instanceof`     | 判断对象是否是某个类型  | "你是不是 XX 类型的人？" |
| `var`（Java 10+）  | 自动推断类型       | "编译器你自己猜是什么类型吧" |

---

## 速查：按学习顺序排列

```
第 1 批（必须最先掌握）：public, class, import, return, void, new, if/else, String, int
    ↓
第 2 批（写业务逻辑必备）：for, while, private, static, final, extends, implements
    ↓
第 3 批（框架开发必备）：try/catch, throw, throws, null, instanceof, abstract, interface
    ↓
第 4 批（进阶理解）：super, protected, default, break, continue, switch/case, var
```

> 类比：学 Java 关键字就像学英语单词——先学"你好、谢谢、是、否"（第 1 批），再学"因为、所以、但是"（第 2 批），然后学"虽然、然而、除非"（第 3 批），最后学一些高级表达（第 4 批）。不需要一次全背下来，用到哪个学哪个最有效。
