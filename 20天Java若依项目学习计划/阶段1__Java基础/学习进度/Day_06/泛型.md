这是 Java 的**泛型方法**语法。让我结合你截图的 `LocalDate.java` 源码来解释：

## 代码解析

```java
public <R> R query(TemporalQuery<R> query) {
    if (query == TemporalQueries.localDate()) {
        return (R) this;
    }
    return ChronoLocalDate.super.query(query);
}
```

## `<R>` 的位置和含义

| 位置 | 代码 | 含义 |
|------|------|------|
| 方法名前面 | `<R>` | **声明**泛型类型参数 |
| 返回类型 | `R` | **使用**泛型，表示返回 R 类型 |
| 参数类型 | `TemporalQuery<R>` | **使用**泛型，表示参数中的 R 类型 |

## 语法结构

```java
public <泛型声明> 返回类型 方法名(参数类型) {
    //     ↑          ↑            ↑
    //   声明R      使用R        使用R
}
```

## 具体例子

```java
// 调用时，R 会被推断为具体类型
String result = localDate.query(TemporalQueries.localDate());
// R = String

LocalDate result = localDate.query(someQuery);
// R = LocalDate
```

## 为什么需要 `<R>` 声明？

```java
// ❌ 错误：R 未声明，编译器不知道 R 是什么
public R query(TemporalQuery<R> query) { }

// ✅ 正确：先声明 R 是泛型参数，再使用
public <R> R query(TemporalQuery<R> query) { }
```

## 对比普通泛型类

```java
// 类级别泛型：整个类都知道 T
public class Box<T> {
    private T item;
}

// 方法级别泛型：只有这个方法知道 R
public <R> R query(TemporalQuery<R> query) { }
```

## 总结

| 符号 | 作用 |
|------|------|
| `<R>` | 声明"这个方法有一个泛型类型叫 R" |
| 返回类型 `R` | "这个方法返回 R 类型" |
| 参数 `TemporalQuery<R>` | "参数中的 R 和返回值的 R 是同一个类型" |

> 简单说：`<R>` 是"自我介绍"（我是泛型），后面的 `R` 是"实际使用"（我用这个类型）。
