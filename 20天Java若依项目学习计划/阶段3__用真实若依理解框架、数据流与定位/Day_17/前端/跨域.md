## 什么是跨域？

**跨域（Cross-Origin）** 是指浏览器出于安全考虑，限制一个网页（前端）去请求另一个不同"源"的服务（后端）的数据。

### "源"由三部分组成：

| 组成部分 | 示例 |
|---------|------|
| **协议** | `http` / `https` |
| **域名（或IP）** | `localhost` / `192.168.1.100` |
| **端口** | `80` / `8080` / `3000` |

只要这三者中**任何一个不同**，就属于跨域。

### 举个例子

你的项目中：

- **前端**运行在：`http://localhost:80`（Vite 开发服务器）
- **后端**运行在：`http://localhost:8080`

虽然都是 `localhost`，但**端口不同**（80 vs 8080），所以浏览器认为这是两个不同的"源"，前端直接请求后端就会被浏览器**拦截**，这就是跨域问题。

### 怎么解决？

你的项目中用的是 **Vite 代理**的方式（如图中所示）：

```
浏览器 → 请求 /dev-api/... → Vite 开发服务器 → 转发到后端
```

前端不直接请求后端，而是请求**同源**的 Vite 开发服务器（`/dev-api/xxx`），Vite 服务器再把请求**转发**到后端。因为服务器之间的请求不受浏览器同源策略限制，所以巧妙地避开了跨域问题。

### 简单类比

> 就像你不能直接去别人家拿东西（跨域被拦截），但你可以让物业（Vite 代理）帮你去拿，物业不受这个限制。
