## 2. Kaptcha 不是"验证码示例库"，而是"验证码生成器"

你的理解需要纠正一下。Kaptcha **不是**一个包含大量现成验证码的"图库"，而是**一个工具**——它负责**实时生成**验证码图片和对应的答案。

### 它的工作原理：

```
每次用户请求验证码时：
    Kaptcha 随机生成文字（如 "AB3D" 或 "3+5"）
        ↓
    用这些文字绘制成一张图片（加干扰线、噪点、扭曲效果）
        ↓
    返回：图片（给用户看）+ 正确答案（存起来，等下比对用）
```

### 项目里配置了两种验证码模式：

**📁 文件：** `backend/ruoyi-framework/src/main/java/com/ruoyi/framework/config/CaptchaConfig.java`

| 模式 | Bean 名称 | 效果 | 示例 |
|------|-----------|------|------|
| **字符型** | `captchaProducer` | 4位随机字母/数字 | `A3kD` |
| **数学型** | `captchaProducerMath` | 随机算式 | `3+5=?` 答案是 `8` |

**数学型验证码的生成逻辑：**

**📁 文件：** `backend/ruoyi-framework/src/main/java/com/ruoyi/framework/config/KaptchaTextCreator.java`

```java
@Override
public String getText() {
    Random random = new Random();
    int x = random.nextInt(10);  // 随机 0~9
    int y = random.nextInt(10);  // 随机 0~9
    int randomoperands = random.nextInt(3);  // 随机选 0/1/2 → 对应 */÷/+-
    
    if (randomoperands == 0) {
        result = x * y;
        suChinese.append(x + "*" + y);       // 显示 "3*5"
    } else if (randomoperands == 1) {
        // 除法或加法...
    } else {
        // 减法（保证结果不为负）...
    }
    
    suChinese.append("=?@" + result);  // 关键！格式："3+5=?@8"
    return suChinese.toString();
    // 图片上显示 "3+5=?"，@后面的 "8" 是正确答案
}
```

> **注意：** 图片上只显示 `3+5=?`，`@8` 这部分不会画到图片上，而是作为答案保存起来。

## 3. 验证码生成的完整流程

**📁 文件：** `backend/ruoyi-admin/src/main/java/com/ruoyi/web/controller/common/CaptchaController.java`

```java
@GetMapping("/captchaImage")
public AjaxResult getCode(HttpServletResponse response) throws IOException {
    AjaxResult ajax = AjaxResult.success();
    
    // ① 检查验证码功能是否开启（从 sys_config 表读取）
    boolean captchaEnabled = configService.selectCaptchaEnabled();
    ajax.put("captchaEnabled", captchaEnabled);
    if (!captchaEnabled) {
        return ajax;  // 没开启就直接返回，不生成验证码
    }

    // ② 生成一个 UUID（唯一标识，用来关联这次验证码请求）
    String uuid = IdUtils.simpleUUID();  // → "a1b2c3d4e5f6..."
    String verifyKey = CacheConstants.CAPTCHA_CODE_KEY + uuid;
    // verifyKey = "captcha_codes:a1b2c3d4e5f6..."

    // ③ 根据配置选择生成哪种验证码
    String captchaType = RuoYiConfig.getCaptchaType();  // 从 application.yml 读取
    
    if ("math".equals(captchaType)) {
        // 数学型：生成 "3+5=?@8"
        String capText = captchaProducerMath.createText();  // → "3+5=?@8"
        capStr = capText.substring(0, capText.lastIndexOf("@"));  // → "3+5=?"（显示在图片上）
        code = capText.substring(capText.lastIndexOf("@") + 1);   // → "8"（正确答案）
        image = captchaProducerMath.createImage(capStr);          // 用 "3+5=?" 生成图片
    }
    else if ("char".equals(captchaType)) {
        // 字符型：生成 "AB3D"
        capStr = code = captchaProducer.createText();  // → "AB3D"
        image = captchaProducer.createImage(capStr);   // 用 "AB3D" 生成图片
    }

    // ④ ★ 把正确答案存入 Redis ★
    redisCache.setCacheObject(verifyKey, code, Constants.CAPTCHA_EXPIRATION, TimeUnit.MINUTES);
    // key = "captcha_codes:a1b2c3d4e5f6..."
    // value = "8"（或 "AB3D"）
    // 有效期 = 2分钟（过期自动删除）

    // ⑤ 把图片转成 Base64 字符串
    FastByteArrayOutputStream os = new FastByteArrayOutputStream();
    ImageIO.write(image, "jpg", os);

    // ⑥ 返回给前端
    ajax.put("uuid", uuid);                              // 唯一标识
    ajax.put("img", Base64.encode(os.toByteArray()));    // 图片的 Base64 编码
    return ajax;
}
```

**返回给前端的数据：**
```json
{
    "code": 200,
    "msg": "操作成功",
    "captchaEnabled": true,
    "uuid": "a1b2c3d4e5f6...",
    "img": "/9j/4AAQSkZJRgABAQEASABIAAD..."  // Base64 编码的图片
}
```

## 4. 为什么要用 Redis？

这是最关键的问题。用一张图来理解：

```
用户A 请求验证码 → 后端生成 "3+5=?" 答案 "8" → 存 Redis
用户B 请求验证码 → 后端生成 "AB3D" 答案 "AB3D" → 存 Redis
用户A 提交登录 → 带着 uuid + 输入的 "8" → 后端用 uuid 从 Redis 取出答案 "8" → 比对
```

### 为什么不用内存（HashMap）存？

| 方案 | 问题 |
|------|------|
| **HashMap（内存）** | ① 服务器重启数据丢失 ② 多服务器部署时数据不共享 ③ 需要自己管理过期清理 |
| **数据库** | ① 验证码是临时数据，写数据库太重 ② 高并发时数据库压力大 |
| **Redis ✅** | ① 自带过期机制（2分钟自动删除）② 支持分布式（多台服务器共享）③ 内存操作，速度极快 |

### Redis 在这里的两个核心作用：

**① 临时存储验证码答案（2分钟过期）**

```
SET captcha_codes:a1b2c3d4  "8"  EX 120
```

- 用户请求验证码时 → **写入** Redis
- 用户提交登录时 → **读取** Redis 比对
- 比对完成后 → **删除** Redis（防止重复使用）
- 2分钟没人用 → **自动过期删除**

**② 通过 UUID 关联"哪张图片对应哪个答案"**

```
前端拿到的：{ uuid: "a1b2c3d4", img: "图片..." }
            ↓ 用户输入验证码后
前端提交的：{ uuid: "a1b2c3d4", code: "8" }
            ↓ 后端用 uuid 查 Redis
Redis 查找：captcha_codes:a1b2c3d4 → "8"
            ↓ 比对
用户输入的 "8" == Redis 中的 "8" → 通过 ✅
```
