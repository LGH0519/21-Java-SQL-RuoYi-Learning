而在 Vue Router 的机制下，当你点击导航切换页面时：
- **后端全程无感知**：浏览器根本不会向服务器请求新的 HTML 页面。
- **前端 JavaScript 接管了一切**：当你输入或点击 `./system/user` 这个路径时，浏览器里的 **Vue Router**（也就是你图里看到的“前台导航/前台”）会立刻拦截这个动作。
- **局部刷新**：Vue Router 会根据预设好的“路由表”，告诉前端代码：“哦，用户要去看用户管理页面了，你把浏览器里那个旧的内容块拿走，换上用户管理页面对应的组件（代码块）。”
- **数据请求**：前端页面换好后，它会悄悄地在后台给后端发一个数据接口请求（比如 `GET /api/users`），后端只返回纯数据（通常是 JSON 格式），前端拿到数据后自己渲染成表格展示在页面上。
