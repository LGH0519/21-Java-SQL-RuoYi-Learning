# D30｜若依前端请求、路由与权限指令

> 今日目标：能说清字典“新增”按钮调用哪个函数、哪个 API URL、哪个 Controller 方法，并将前端 `v-hasPermi` 与后端权限注解对照。

## 1. 知识速记

- `src/api/...` 封装 HTTP 请求；Vue 页面导入并调用它。
- Vite 开发环境把 `/dev-api` 代理到后端；Network 显示的是浏览器实际请求。
- `v-hasPermi` 控制前端按钮可见性；`@PreAuthorize` 是后端真实授权检查。
- 路由/菜单决定页面可进入的位置，权限决定用户能否看到/调用。

## 2. 资料

- `frontend\src\api\system\dict\type.js`
- `frontend\src\views\system\dict\index.vue`
- `backend\ruoyi-admin\src\main\java\com\ruoyi\web\controller\system\SysDictTypeController.java`
- `frontend\vite.config.js`、`frontend\.env.development`

## 3. 知识详解

“页面没有按钮”可能是 `v-hasPermi` 隐藏；“接口仍能被调用”取决于后端 `@PreAuthorize` 是否拒绝。两边权限字符串需一致。API 文件中的 `url`、`method`、`data/params` 直接对应 Network 请求；读取 JSON 通常 `data`，查询参数通常 `params`，以项目封装实际写法为准。

4. 写一句：前端隐藏提升体验，后端校验负责安全。
