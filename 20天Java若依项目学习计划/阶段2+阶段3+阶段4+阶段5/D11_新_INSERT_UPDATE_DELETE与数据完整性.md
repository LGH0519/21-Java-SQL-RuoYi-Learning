## 知识点速记（完成当天任务后用于复习）

- **INSERT：**明确列名插入，避免依赖列顺序。
- **UPDATE/DELETE：**WHERE 是安全边界，先 SELECT 预览再执行。
- **NULL：**表示未知/未设置，不等于空字符串或 0。
- **完整性：**非空、唯一、正确类型、合法状态共同保护数据。

### 本日必须形成的业务映射

档案录入会成为 INSERT；归还会成为 UPDATE；删除前必须检查档案状态和关联数据。

### 本日重点、易混点与易面试点

漏 WHERE 会影响全表；DELETE 是物理删除；`= NULL` 不正确，应使用 IS NULL；客户端自动提交不等于事务已学会。

## 任务参考答案（完成后再查看）

标准安全顺序是先 SELECT 使用同一个 WHERE 预览行，再 UPDATE/DELETE，最后再 SELECT 验证。编号/名称是文本需加引号；数值通常不加；NULL 用 IS NULL 判断。
