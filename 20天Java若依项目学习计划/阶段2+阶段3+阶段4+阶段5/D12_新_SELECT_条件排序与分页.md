## 知识点速记（完成当天任务后用于复习）

- **WHERE：**用比较、IN、BETWEEN、LIKE、IS NULL 筛选行。
- **排序分页：**ORDER BY 必须稳定；LIMIT offset,size 表示跳过多少行后取多少行。
- **动态 SQL：**MyBatis `<if>` 在参数有值时才加入条件。
- **参数安全：**`#{}` 绑定参数；不要把用户输入用 `${}` 拼接。

### 本日必须形成的业务映射

页面输入档案名称/状态/分类，会变成查询参数；Mapper XML 根据参数决定 SQL 条件；列表再返回 rows/total。

### 本日重点、易混点与易面试点

LIKE `%合同%` 与 `合同%` 范围不同；WHERE x = NULL 错，应 IS NULL；无排序分页可能不稳定；页面没结果先看参数而不是直接改 SQL。

## 任务参考答案（完成后再查看）

`LIMIT 3,3` 是跳过前三行后取三行；空值用 `IS NULL`；名称包含用 `LIKE '%关键字%'`。XML 的 if 只在参数非空时拼入对应 AND 条件。
