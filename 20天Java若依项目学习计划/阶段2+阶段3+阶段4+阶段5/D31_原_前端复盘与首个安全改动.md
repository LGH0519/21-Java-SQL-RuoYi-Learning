# Day 31：前端复盘与首个安全改动

> 今日目标：定位字典菜单打开页面的关系，只做一个可回退的显示文字或列宽改动，用 Git 确认 diff。

## 知识点速记（完成当天任务后复习）

- 菜单/路由把 URL 和 Vue 组件联系起来；API 文件把页面动作和后端 URL 联系起来。
- 热更新只说明前端显示改变，不表示后端/数据库改变。
- 小改动原则：一次只改一个明确展示点；先看 diff，再决定提交或撤回。

## 视频、文档与若依对应点

- D30 的三个字典文件。
- [Git 官方：查看改动](https://git-scm.com/docs/git-diff)：只看 `git diff`。

## 本日重点、易混点与若依对应

“菜单为什么打开 index.vue”要追菜单路由/组件配置，不能只猜文件名。学习修改选展示文案或列宽，因为它不影响 API、权限和数据；不要在首个改动时重构页面、升级 Node 依赖或改动生成代码。

## 今天照做（09:00–23:00）

### 09:00–12:00｜定位菜单到页面

1. 在 DBeaver 若依库只读查询 `sys_menu` 中“字典”相关菜单，查看 path/component（字段按真实表结构）。
2. 在前端项目搜索该 component 路径或 `dict/index`，确认它对应 `src/views/system/dict/index.vue`。
3. 写路径：菜单记录→路由→组件文件。若是动态路由，以项目实际加载机制为准，只记录证据。

### 15:00–18:00｜只改一个展示点

1. Git Bash/终端进入 `E:\WorkSpace\ruoyi-archive-management`，执行 `git status`；若已有非你本次学习的改动，记录并不要碰。
2. IDEA 打开 `index.vue`，只把一个明显的显示文字改为“字典类型（学习验证）”，或仅把一个表格列 width 微调。不要改变量名、接口、权限、格式化整文件。
3. 保存，观察开发服务器热更新或刷新页面。截图改前/改后（至少改后）。

### 19:00–23:00｜Git 确认与回退决策

1. 终端执行 `git diff -- frontend/src/views/system/dict/index.vue`，核对只有预期一处。
2. 若这是你希望保留的学习标记，执行 `git add`、`git commit -m "docs: verify dict page display"`（仅在 status 确认无无关文件后）。
3. 若仅临时练习，不使用危险的整仓重置；在 IDEA 将你刚改的那一行手工改回原文字，再次 `git diff` 确认无本次 diff。
