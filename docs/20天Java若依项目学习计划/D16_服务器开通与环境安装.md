# Day 16：拿到一台可部署的 Linux 服务器

## 今日成果

可 SSH 登录服务器；JDK、MySQL、Redis、Nginx 安装/运行正常；数据库由非 root 应用账号访问。

## 授权边界

开通云服务器涉及付费，由你自行选择厂商和支付。建议最低 2 核 4GB Linux；先用公网 IP，不强求域名。

| 时间 | 知识点 | 如何学习和操作 | 验收 |
|---|---|---|---|
| 09:00–10:00 | 云服务器安全 | 开通后记录公网 IP；设置强密码或 SSH 密钥；只自己保存密钥。 | 可 SSH 登录。 |
| 10:00–12:00 | 防火墙/端口 | 仅放行 SSH、HTTP/HTTPS 和应用实际端口；不要开放 MySQL 3306 公网。 | `ss -lntp` 截图。 |
| 15:00–16:00 | JDK | 安装与本地项目兼容的 JDK；执行 `java -version`。 | 版本与项目要求匹配。 |
| 16:00–17:00 | MySQL | 安装、启动、设置 root 初始安全；本机服务器上登录一次。 | `SELECT VERSION()` 成功。 |
| 17:00–18:00 | Redis/Nginx | 安装、启动；检查服务状态。 | 两服务状态正常。 |
| 19:00–20:30 | 数据库账号 | 创建 `archive_app` 等非 root 账号，仅授予目标库权限；导入主项目 SQL。 | DBeaver 或命令行用应用账号能登录。 |
| 20:30–22:00 | 服务器目录 | 创建明确目录：`/opt/archive-app`、`/var/log/archive-app`、`/opt/library-api`。 | 目录权限正确。 |
| 22:00–23:00 | 记录与提交 | 将部署步骤写入私有笔记/README 模板，**不提交密码/IP 密钥**。 | Day 16 日志。 |

## 必须验收

- [ ] MySQL 3306 不对公网开放。
- [ ] 应用不使用 root 数据库账号。
