# 前端最小知识集（读懂本项目）

每个技术方向只给一个官方网址。读代码时先对照知识点清单认出"这是什么"，不认识的再去对应网址搜索。

| 技术 | 网址 |
|---|---|
| HTML | https://developer.mozilla.org/zh-CN/docs/Web/HTML |
| CSS | https://developer.mozilla.org/zh-CN/docs/Web/CSS |
| JavaScript | https://zh.javascript.info/ |
| Vue3 | https://cn.vuejs.org/ |

一个重要习惯：`.vue` 文件里的代码不全是 Vue 语法，先判断"这段写法属于谁"（HTML？JS？Vue？Element Plus？若依封装？），再理解作用。示例尽量取自本项目源码。

## 一、HTML（约半天）

### 1. 标签与属性
```html
<div class="app-container">内容</div>
```
页面由成对标签组成。`class` 是属性名，`"app-container"` 是属性值。

### 2. 常用标签
```html
<div>划分区域</div>
<span>行内小段文字</span>
<a href="/login">链接</a>
```
`div` 划分区域、`span` 行内文字、`a` 链接、`img` 图片、`table` 表格、`form / input / button` 表单。

### 3. 嵌套与自闭合
```html
<div>
  <h2>标题</h2>
  <span>说明</span>
</div>
```
内层标签属于外层标签的内容，开始和结束标签必须成对。没有内容的标签（或组件）可以自闭合：`<pagination />`。

### 4. 表单元素（了解）
```html
<input type="text" />
<select><option>选项</option></select>
```
这是 Element Plus 表单组件的原型，认识即可，实际开发直接用 `el-input` 等。

## 二、CSS（约 1-2 天）

### 5. 类选择器
```css
.app-container {
  padding: 20px;
}
```
按 `class` 匹配元素。项目里绝大多数样式都是类选择器。

### 6. 盒模型
```css
.box {
  width: 100px;
  padding: 10px;   /* 内边距 */
  border: 1px;     /* 边框 */
  margin: 20px;    /* 外边距 */
}
```
每个元素是一个盒子：内容 + `padding`（内边距）+ `border`（边框）+ `margin`（外边距）。

### 7. flex 布局
```css
.container {
  display: flex;              /* 子元素横向排列 */
  justify-content: center;    /* 主轴对齐 */
  align-items: center;        /* 交叉轴对齐 */
}
.child { flex: 1; }           /* 占据剩余空间 */
```
本项目布局核心，侧边栏、顶栏、表单行都靠它。

### 8. position 定位
```css
.parent { position: relative; }
.badge  { position: absolute; top: 0; right: 0; }
```
`relative` 相对自身、`absolute` 相对最近的定位父级、`fixed` 相对视口。弹窗、悬浮按钮常用。

### 9. 常用单位
`px` 像素（固定）、`%` 相对父级、`rem` 相对根字号、`vh/vw` 视口高/宽（满屏布局用）。

### 10. SCSS 基础
```scss
$bg-color: #fff;
.sidebar {
  background: $bg-color;
  .menu { color: red; }     /* 嵌套，等于 .sidebar .menu */
  &:hover { color: blue; }  /* & 是父选择器自身 */
}
```
项目样式全是 `.scss`，会读即可。

## 三、JavaScript（重点，约 1-2 周）

### 基础语法

### 11. let / const
```js
const total = 0    // 不可重新赋值
let count = 0      // 可重新赋值
count = 10         // 允许
```
项目里默认用 `const`，只有确实要重新赋值时才用 `let`。

### 12. 数据类型
```js
const name = "张三"   // 字符串
const count = 10      // 数字
const ok = false      // 布尔
const empty = null    // 空
```
注意后端返回的状态值常是字符串 `"1"`，不是数字 `1`，用 `===` 比较时不能混。

### 13. 对象
```js
const form = { realName: "张三", status: "1" }
form.status = "2"        // 修改
console.log(form.realName) // 读取
```
键值对集合，接口返回的数据基本都是对象。

### 14. 数组
```js
const list = ["a", "b", "c"]
list[0]        // "a"，下标从 0 开始
list.length    // 3
```
有序集合，表格数据、路由表都是数组。

### 15. 函数
```js
function handleQuery() { }        // 普通函数
const load = (id) => { }          // 箭头函数
load(123)
```
箭头函数是简写：单参数可省括号、函数体单行可省大括号。本项目里箭头函数到处都是。

### 16. if 判断与逻辑运算符
```js
if (status === "1" && visible) { }
```
`===` 严格相等、`!==` 严格不等、`&&` 与、`||` 或、`!` 取反。后端转来的要用 `===`，避免 `"1" == 1` 这类隐式转换。

### 17. 三元表达式
```js
const text = status === "2" ? "通过" : "未通过"
```
`条件 ? 成立的值 : 不成立的值`，简单判断用，复杂逻辑用 `if` 更易读。

### 18. 模板字符串
```js
`/user/${id}`                 // 等价 "/user/" + id
`/registration/manage/${registrationId}`
```
反引号内用 `${}` 嵌变量，api 文件里的接口地址都是这种写法。

### 19. 解构赋值
```js
const { token } = getTokenObj()   // 等价 token = getTokenObj().token
const [first, second] = list      // 数组解构
```
直接从对象/数组中取值，读代码时看到花括号在等号左边就是解构。

### 20. 展开运算符 ...
```js
return { ...to, replace: true }   // 拷贝 to 的所有属性，再覆盖 replace
const merged = { ...a, ...b }     // 合并对象
const copied = [...arr]           // 拷贝数组
```
路由守卫 `permission.js` 里 `{ ...to, replace: true }` 就是"复制当前路由信息，附加 replace"。

### 21. 对象属性 / 方法简写
```js
// permission.js 中的 Pinia actions
actions: {
  generateRoutes(roles) { }   // 等价 generateRoutes: function(roles) { }
}
const name = "x"
const obj = { name }          // 等价 { name: name }
```
对象里的 `方法名() {}` 是 ES6 方法简写，读 store 源码必须认识。

### 22. 默认参数
```js
// permission.js L59
function filterAsyncRouter(asyncRouterMap, lastRouter = false, type = false) { }
```
调用没传的参数自动用默认值，所以 `filterAsyncRouter(sdata)` 时 `type` 是 `false`。

### 23. 可选链 ?. 与空值合并 ??
```js
const list = res.data?.rows        // res.data 为空时不报错，返回 undefined
const title = form.title ?? "无"   // 前者为 null/undefined 时取后者
```
安全读取深层属性，避免 `Cannot read properties of undefined` 报错。

### 24. import / export
```js
// api/menu.js 导出
export const getRouters = () => { }

// store/modules/permission.js 导入
import { getRouters } from '@/api/menu'
```
一个文件导出、另一个文件导入。导出名、导入名、路径三者必须对上，`@` 是 src 目录别名。

### 数组方法

### 25. forEach
```js
// permission.js L49
accessRoutes.forEach(route => {
  router.addRoute(route)
})
```
遍历数组对每项执行操作，无返回值。`route` 由 forEach 自动传入，每轮是当前元素。

### 26. map
```js
const names = users.map(u => u.name)   // 返回新数组 ["张三", "李四"]
```
遍历并转换每一项，返回等长的新数组，不改变原数组。

### 27. filter
```js
// permission.js 中 filterAsyncRouter 的内部
asyncRouterMap.filter(route => {
  return true    // 返回 true 的项保留在新数组中
})
```
按条件过滤，返回满足条件的新数组。原数组不变。

### 28. find / some / includes
```js
list.find(item => item.id === 1)   // 第一个满足的元素，没有则 undefined
list.some(item => item.ok)         // 是否存在满足项，返回布尔
roles.includes("admin")            // 数组是否包含某值
```
查找与判断类方法，权限判断常用。

### 异步（前面已实战过）

### 29. Promise
```js
// permission.js L36
return new Promise(resolve => {   // resolve 是引擎自动传入的兑现函数
  getRouters().then(res => {
    resolve(rewriteRoutes)        // 调 resolve 即"兑现"，把值传给外部 await
  })
})
```
异步结果的"承诺单"：pending（等待）→ fulfilled（兑现）/ rejected（拒绝）。每个 Promise 配对自己的 resolve。

### 30. then / catch / finally
```js
getRouters()
  .then(res => { })     // 成功后执行，res 是兑现值
  .catch(err => { })    // 失败后执行
  .finally(() => { })   // 无论成败都执行，常用来关 loading
```
链式写法，前一步的返回值交给下一步。

### 31. async / await
```js
// permission.js L48
const accessRoutes = await usePermissionStore().generateRoutes()
```
`await` 等 Promise 兑现并取出值，写起来像同步代码；只能用在 `async` 函数里。`await` 拿到的是 resolve 传出的值，不是 Promise 本身。

### 32. 事件循环（了解）
同步代码先执行完 → 微任务（`Promise.then`）→ 宏任务（`setTimeout`）。解释了"为什么外层 executor 先结束、`.then` 回调后执行"。

### 其他

### 33. JSON.parse / JSON.stringify
```js
// permission.js L39，深拷贝写法
const sdata = JSON.parse(JSON.stringify(res.data))
```
`stringify` 对象转字符串、`parse` 字符串转对象；两者连用等于深拷贝，让三份数据互不影响。

### 34. 闭包
```js
new Promise(resolve => {          // resolve 是外层函数的形参
  getRouters().then(res => {
    resolve(rewriteRoutes)        // 内层回调通过闭包抓着外层的 resolve 不放
  })
})
```
内层函数引用外层函数的变量，外层执行完后变量仍可用。没有闭包，`.then` 回调里就调不到 resolve。

### 35. setTimeout / setInterval
```js
setTimeout(() => { }, 1000)       // 1 秒后执行一次
const timer = setInterval(() => { }, 5000)  // 每 5 秒执行
clearInterval(timer)              // 停止
```
延时/定时任务，锁屏倒计时、防抖等场景用。

### 36. 浏览器存储
```js
localStorage.setItem("key", "值")   // 持久存储
sessionStorage.getItem("key")       // 会话级存储
document.cookie                     // 读 cookie
```
`utils/auth.js` 用 js-cookie 库存 token，本质是简化了的 cookie 读写。

## 四、Vue3（核心，约 1-2 周）

### 文件结构

### 37. .vue 三段结构
```vue
<template>页面结构</template>

<script setup>
// 数据和逻辑
</script>

<style scoped>
/* 当前组件的样式 */
</style>
```
`scoped` 表示样式只作用于当前组件，减少污染其他页面。

### 38. main.js 入口
```js
const app = createApp(App)
app.use(router)          // 注册路由
app.use(pinia)           // 注册状态管理
app.use(ElementPlus)     // 注册组件库
app.mount('#app')
```
应用起点：创建实例、注册插件、挂载到页面。

### 模板语法

### 39. 插值 {{ }}
```html
<span>{{ user.name }}</span>
<span>{{ auditOpinion || "无" }}</span>
```
把 JS 数据显示到页面，可写简单表达式；复杂逻辑放 `script` 里。

### 40. 动态绑定 :
```html
<el-button :disabled="saving">保存</el-button>
```
`:` 是 `v-bind` 简写，引号内是 JS 表达式。`disabled="false"` 只是字符串，`:disabled="false"` 才是布尔值。

### 41. 事件绑定 @
```html
<el-button @click="handleQuery">查询</el-button>
<el-input @keyup.enter="handleQuery" />       <!-- 回车触发 -->
```
`@` 是 `v-on` 简写。可带参数：`@click="fn(row)"`。

### 42. v-if / v-show
```html
<div v-if="status === '3'">审核不通过</div>
<div v-show="visible">内容</div>
```
`v-if` 假时元素不创建；`v-show` 假时元素还在，只是 CSS 隐藏。频繁切换用 `v-show`，普通条件用 `v-if`。

### 43. v-else-if / v-else
```html
<div v-if="status === '2'">通过</div>
<div v-else-if="status === '3'">不通过</div>
<div v-else>未审核</div>
```
必须紧跟对应的 `v-if`，中间不能插别的元素。

### 44. v-for
```html
<el-option
  v-for="item in dictList"
  :key="item.value"
  :label="item.label"
  :value="item.value"
/>
```
遍历数组生成元素。`item` 是当前项，`:key` 帮 Vue 识别每一项，一般不给下标。

### 45. v-model
```html
<el-input v-model="form.realName" />
<el-dialog v-model="dialogVisible">
```
双向绑定：输入框内容变化 → 数据变化，数据变化 → 输入框同步。弹窗上 `true` 打开、`false` 关闭。

### 组合式 API

### 46. ref()
```js
const total = ref(0)
total.value = 10          // 脚本中必须 .value
```
```html
<span>{{ total }}</span>   <!-- 模板中不用 .value -->
```
把普通值变成响应式数据，值变了页面自动更新。脚本要 `.value`、模板不要——初学最易混淆点。

### 47. reactive()
```js
const form = reactive({ realName: "", status: "0" })
form.realName = "张三"    // 直接改，不需要 .value
```
也能创建响应式对象。本项目习惯用 `ref` 包对象，认识即可。

### 48. computed
```js
const double = computed(() => count.value * 2)
```
计算属性：依赖变了自动重新计算。适合"由现有数据算出来的数据"。

### 49. watch / watchEffect
```js
watch(() => form.status, (newVal) => {
  console.log("状态变了", newVal)
})
```
监听数据变化后执行操作，如联动查询、重置表单。

### 50. 生命周期 onMounted
```js
onMounted(() => {
  loadList()      // 页面加载完自动查列表
})
```
组件挂载完成后执行。常见用途：初次查询、加载字典、初始化数据。

### 51. defineProps / defineEmits
```js
const props = defineProps({ modelValue: Boolean })   // 接收父组件传的参数
const emit = defineEmits(["update:modelValue"])      // 声明可发出的事件
emit("update:modelValue", false)
```
`script setup` 组件对外的"入口"和"出口"。

### 52. provide / inject
```js
// 祖先组件
provide("theme", dark)
// 后代组件
const theme = inject("theme")
```
跨层级传数据，避免一层层传 props。本项目主题配置等用到。

### 组件

### 53. 组件与来源
| 组件 | 来源 |
|---|---|
| `el-button / el-table / el-form` | Element Plus |
| `pagination / dict-tag / RightToolbar` | 若依封装 |
| 页面里的其他标签 | 业务组件（本项目 views 目录） |

先分清来源，再决定去哪查文档（Element Plus 官网还是本项目源码）。

### 54. props 传参
```html
<dict-tag :options="sys_normal_disable" :value="row.status" />
```
父组件向子组件传数据。子组件用 `defineProps` 声明后才能收到。

### 55. 插槽 slot
```html
<el-table-column label="操作">
  <template #default="scope">
    <el-button @click="fn(scope.row)">编辑</el-button>  <!-- scope.row 当前行 -->
  </template>
</el-table-column>

<el-dialog>
  <template #footer>    <!-- 内容放到弹窗底部区域 -->
    <el-button>关闭</el-button>
  </template>
</el-dialog>
```
插槽决定组件某个区域显示什么。`#default` / `#footer` 是具名插槽。

### 56. 组件引用 ref
```html
<el-form ref="formRef">
```
```js
const formRef = ref()
formRef.value.validate(valid => { })   // 调组件暴露的方法
```
模板 `ref="xxx"` 取组件实例；与 `ref()` 创建响应式数据同名不同用途。

### 57. 动态组件
```html
<component :is="currentComponent" />
```
`:is` 传组件名或组件对象，按值切换渲染。动态路由的页面渲染靠它。

### 全家桶

### 58. Vue Router
```js
// permission.js 路由守卫：每次跳转前执行
router.beforeEach(async (to, from) => { })

// 动态注册路由
router.addRoute(route)
```
页面里用 `useRouter()` 拿跳转方法、`useRoute()` 拿当前路由参数。文档：https://router.vuejs.org/zh/

### 59. Pinia
```js
// store/modules/permission.js
const usePermissionStore = defineStore("permission", {
  state: () => ({ routes: [] }),        // 存数据
  actions: { generateRoutes() { } }     // 存方法
})
// 任意组件中使用
const store = usePermissionStore()
store.routes
```
全局状态管理，多组件共享的数据（用户信息、路由、主题）都放这。文档：https://pinia.vuejs.org/zh/

### 60. Axios
```js
// api/menu.js，request 是若依封装的 axios 实例
return request({
  url: "/getRouters",
  method: "get",
  params: query        // GET 查询参数 → ?a=1&b=2
  // data: form        // POST/PUT 请求体
})
```
`utils/request.js` 里拦截器统一加 token、统一处理错误提示。接口返回：普通接口取 `res.data`，分页取 `res.rows / res.total`。
