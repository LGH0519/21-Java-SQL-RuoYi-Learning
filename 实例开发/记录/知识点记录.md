3、
```
用户点击“保存”
       ↓
通过 ref 找到整张表单
       ↓
表单根据 rules 中的规则进行校验
       ↓
通过 prop 找到每个字段对应的规则
       ↓
全部通过后才调用后端接口
```
表单校验，就是在保存或者提交之前，检查用户填写的数据是否符合要求。
`ref` 在这里可以理解为：给页面上的某个组件取一个名字，方便 JavaScript 找到并操作它。
`rules` 用来定义每一个字段需要满足什么条件。
`prop` 用来说明这个 `el-form-item` 对应 `form` 中的哪一个字段。

|内容|作用|示例|
|---|---|---|
|`:model="form"`|指定整张表单的数据|`form.realName`|
|`ref="personalRef"`|给表单组件一个引用，方便JS操作|`personalRef.value.validate()`|
|`:rules="rules"`|指定整张表单使用的校验规则|必填、长度、格式|
|`prop="realName"`|将某一项与数据和规则对应起来|对应 `form.realName`|

14、序列化：把Java对象转换成可以保存或传输的数据形式。序列化后，可以用于：

需要注意：Java序列化和“返回给前端的JSON”不是完全相同的机制。返回JSON通常由Jackson完成：`Java对象 → JSON`。Java原生序列化通常是：`Java对象 → 二进制数据`。

```
form       变量，保存ref响应式对象
draftData  变量，保存普通对象
const form = ref({}) 变量本身不能重新赋值，但可以修改，即form.value = {}
ref() 给数据套上一层Vue可以观察的包装；const保证外层变量不能改指向，.value中的内容仍然可以修改。
```

31、`v-model="form.realName"`负责输入框与字段的双向绑定
```
<el-input v-model="form.realName" />
相当于
<el-input
  :model-value="form.realName"
  @update:model-value="form.realName = $event"
/>
```
`v-model` 可以不借助 `el-form` 的 `:model` 实现双向绑定；它也不强制必须使用 `ref()`，但必须绑定到一个存在且可修改的数据，而在Vue页面中通常用 `ref()` 或 `reactive()` 让这个数据具有响应式能力。
```
v-model
负责连接输入框和字段

ref()或reactive()
负责创建Vue能够追踪的数据

:model="form"
负责把整份数据交给el-form管理和校验
```

34、prop="auditResult"，`prop` 是 `el-form-item` 在表单数据中的“字段地址”，表单校验会利用它找到字段值和对应规则。
```
:model="auditForm"
        │
        ├── auditForm.auditResult  ← 表单数据
        │
prop="auditResult"                 ← 指定当前校验哪个字段
        │
:rules="auditRules"
        └── auditRules.auditResult ← 查找该字段的校验规则
1. 找到 prop="auditResult" 的 el-form-item
2. 从 auditForm 中读取 auditResult 的值
3. 从 auditRules 中找到 auditResult 对应的规则
4. 判断当前值是否符合规则
5. 不符合就在该 el-form-item 下显示错误信息
v-model="auditForm.auditResult"负责输入框的数据绑定。
```
35、v-model:page="queryParams.pageNum"
```
点击页码 2
    ↓
Pagination 组件知道当前页变成 2
    ↓
组件触发 update:page 事件，并传出 2
    ↓
v-model:page 自动执行 queryParams.pageNum = 2
    ↓
触发 @pagination="getList"
    ↓
用新的 pageNum=2 查询第二页数据
```
可以把 `v-model:page` 理解为 `v-model` 的“指定属性版本”。`v-model:page` 的完整写法相当于：
```
<pagination
  :page="queryParams.pageNum"  //指定绑定分页组件的page属性，而不是默认的modelValue。
  @update:page="queryParams.pageNum = $event"
/>
```
当父组件希望把一个变量交给子组件显示，并允许子组件反过来修改这个变量时，使用 `v-model`。
普通 `v-model` 默认绑定组件的 `modelValue` 属性。
```
v-model       → 默认绑定 modelValue
v-model:page  → 指定绑定 page
v-model:limit → 指定绑定 limit
```
只把值交给组件显示，不希望组件反向修改，使用单向绑定 `:`
只监听某个动作，使用 `@`
