可以。先建立一个很重要的认识：`.vue` 文件里的代码并不全是 Vue 语法，它通常混合了四类内容：

| 来源                | 例子                                    |
| ----------------- | ------------------------------------- |
| HTML              | `<div>`、`<span>`                      |
| JavaScript        | `const`、`if`、函数、Promise               |
| Vue               | `v-if`、`v-model`、`ref()`              |
| Element Plus / 若依 | `<el-form>`、`<dict-tag>`、`v-hasPermi` |

你学习时必须先判断“这段写法属于谁”，否则很容易把 Element Plus 组件误认为Vue自带功能。

下面按照学习优先级列出清单。

## 一、`.vue` 文件的基本结构

### 1. `<template>`

负责页面结构。

```
<template>
  <div>个人报名</div>
</template>
```

可以理解为“页面要显示什么”。

需要掌握：

- 标签的开始和结束；
- 标签嵌套；
- 属性写法；
- 页面中只能有合理的结构关系。

### 2. `<script setup>`

负责数据和操作逻辑。

```
<script setup>
const name = ref("张三")
</script>
```

例如查询接口、按钮点击、表单数据、弹窗状态都写在这里。

`setup` 是Vue 3的组合式API写法。你现在先掌握项目中的这种写法，不必同时学习Vue 2的 `data()`、`methods`。

### 3. `<style>`

负责页面样式。

```
<style scoped>
.title {
  color: blue;
}
</style>
```

`scoped` 表示样式主要作用于当前组件，减少对其他页面的影响。

当前阶段掌握：

- 类选择器；
- 宽度、高度、边距；
- 字体、颜色；
- Flex布局。

## 二、HTML基础

### 4. 标签

```
<div>内容区域</div>
<span>行内文字</span>
```

`div` 常用于划分区域，`span` 常用于显示小段文字。

### 5. 标签属性

```
<div class="app-container">
```

这里：

- `class` 是属性名；
- `"app-container"` 是属性值。

### 6. 标签嵌套

```
<div>
  <h2>报名管理</h2>
  <span>待审核</span>
</div>
```

内层标签属于外层标签的内容。必须注意开始标签和结束标签是否成对。

### 7. 自闭合标签

```
<pagination />
```

相当于：

```
<pagination></pagination>
```

没有额外内容的组件可以这样写。

## 三、JavaScript基础

这些不是Vue专属语法，但 `.vue` 文件大量使用。

### 8. `const` 和 `let`

```
const total = ref(0)
let count = 0
```

- `const`：变量本身不重新赋值；
- `let`：变量可以重新赋值。

Vue项目里通常优先使用 `const`。

注意：

```
const form = ref({})
form.value = {}
```

这是允许的，因为没有让 `form` 指向另一个 `ref`，只是修改了 `form.value`。

### 9. 字符串、数字、布尔值和 `null`

```
const name = "张三"       // 字符串
const count = 10          // 数字
const visible = false     // 布尔值
const detail = null       // 暂时没有对象
```

报名状态 `"1"` 是字符串，不是数字 `1`。

### 10. 对象

```
const form = {
  realName: "张三",
  status: "1"
}
```

读取属性：

```
form.realName
form.status
```

修改属性：

```
form.status = "2"
```

### 11. 数组

```
const statuses = ["1", "2", "3"]
```

判断数组中是否包含某个值：

```
statuses.includes("2")
```

项目中的：

```
["2", "3"].includes(registrationDetail.status)
```

表示当前状态是否为审核通过或审核不通过。

### 12. 函数

```
function handleQuery() {
  loadRegistrationList()
}
```

函数是一组可以重复调用的操作。

带参数的函数：

```
function loadDetail(registrationId) {
  console.log(registrationId)
}
```

### 13. `return`

```
return getRegistrationList()
```

`return` 把结果交给调用这个函数的代码，也可以结束函数。

```
if (!valid) {
  return
}
```

表示校验失败后立即停止，不再继续提交。

### 14. `if` 条件判断

```
if (form.value.status === "1") {
  console.log("待审核")
}
```

需要掌握：

- `===`：严格相等；
- `!==`：严格不相等；
- `&&`：并且；
- `||`：或者；
- `!`：取反。

例如：

```
if (saving.value || submitting.value) {
  return
}
```

表示正在保存或者正在提交时，都不允许重复操作。

### 15. 三元表达式

```
const text = status === "2" ? "通过" : "未通过"
```

结构是：

```
条件 ? 条件成立的值 : 条件不成立的值
```

简单判断可以使用；复杂业务建议使用 `if`，更容易阅读。

### 16. 模板字符串与字符串拼接

当前项目使用了：

```
"/registration/manage/" + registrationId
```

也可以写成：

```
`/registration/manage/${registrationId}`
```

两者结果相同。

### 17. 解构赋值

```
const { proxy } = getCurrentInstance()
```

相当于从对象中取出 `proxy` 属性。

```
const proxy = getCurrentInstance().proxy
```

若依中常通过 `proxy` 使用全局功能：

```
proxy.$modal.msgSuccess("保存成功")
```

### 18. `import` 和 `export`

导出函数：

```
export function getRegistrationList() {
}
```

在另一个文件中导入：

```
import {
  getRegistrationList
} from "@/api/registration/manage"
```

需要掌握：

- 导出名和导入名必须一致；
- 文件路径必须正确；
- 没有导出的函数不能被其他文件导入。

## 四、Vue响应式基础

### 19. `ref()`

```
const total = ref(0)
```

`ref()` 把普通值变成响应式数据。值发生变化时，Vue会更新页面。

在JavaScript中读取或修改需要 `.value`：

```
total.value = 10
```

在模板中不用写 `.value`：

```
<span>{{ total }}</span>
```

这是初学者最容易混淆的地方之一。

### 20. `reactive()`

```
const form = reactive({
  realName: "",
  status: "0"
})
```

它也能创建响应式对象。

你目前项目主要使用：

```
const form = ref({
  realName: "",
  status: "0"
})
```

现阶段先熟悉 `ref()`，暂时不需要频繁混用两种方式。

### 21. `Object.assign()`

```
Object.assign(form.value, {
  realName: response.data.realName,
  status: response.data.status
})
```

作用是把右侧对象的字段复制到左侧对象中。

它常用于把接口返回数据填入表单。

### 22. `onMounted()`

```
onMounted(() => {
  loadRegistrationList()
})
```

表示页面组件创建并挂载完成后执行。

常见用途：

- 初次查询列表；
- 查询当前用户信息；
- 加载字典；
- 初始化页面数据。

### 23. 箭头函数

```
response => {
  registrationList.value = response.rows
}
```

它是一种函数写法，大致相当于：

```
function (response) {
  registrationList.value = response.rows
}
```

项目中的 `.then()`、`.finally()` 经常使用箭头函数。

## 五、模板数据显示

### 24. 插值表达式 `{{ }}`

```
<span>{{ registrationDetail.realName }}</span>
```

把JavaScript数据显示在页面上。

可以写简单表达式：

```
{{ registrationDetail.auditOpinion || "无" }}
```

表示审核意见为空时显示“无”。

不要在 `{{ }}` 中写很复杂的业务逻辑。

### 25. 动态属性绑定 `:`

普通属性：

```
width="600px"
```

动态绑定：

```
:disabled="auditSubmitting"
```

冒号是 `v-bind` 的简写：

```
v-bind:disabled="auditSubmitting"
```

区别：

```
disabled="false"
```

这里的 `"false"` 只是字符串，可能仍然表示禁用。

```
:disabled="false"
```

这里才是JavaScript布尔值 `false`。

### 26. `v-model`

```
<el-input v-model="form.realName" />
```

它实现双向绑定：

```
输入框内容变化 → form.realName变化
form.realName变化 → 输入框内容变化
```

常用于：

- 输入框；
- 下拉框；
- 单选框；
- 弹窗显示状态。

例如：

```
<el-dialog v-model="auditDialogVisible">
```

`true` 时打开弹窗，`false` 时关闭。

### 27. `v-if`

```
<div v-if="form.status === '3'">
  审核不通过
</div>
```

条件为 `true` 时才创建并显示该元素。

### 28. `v-else-if` 和 `v-else`

```
<div v-if="status === '2'">
  审核通过
</div>

<div v-else-if="status === '3'">
  审核不通过
</div>

<div v-else>
  尚未审核
</div>
```

它们必须紧跟在对应的 `v-if` 后面。

### 29. `v-show`

```
<div v-show="visible">
  内容
</div>
```

与 `v-if` 的区别：

- `v-if` 为假时，元素不创建；
- `v-show` 为假时，元素还在，只是通过CSS隐藏。

经常频繁显示/隐藏时可以考虑 `v-show`；普通条件区域先用 `v-if`。

### 30. `v-for`

```
<el-option
  v-for="item in registration_position"
  :key="item.value"
  :label="item.label"
  :value="item.value"
/>
```

表示遍历职位数组，为每一项创建一个下拉选项。

需要理解：

- `item`：当前遍历到的数据；
- `item.label`：显示名称；
- `item.value`：保存的字典值；
- `:key`：帮助Vue识别每一项。

### 31. 事件绑定 `@`

```
<el-button @click="handleQuery">
  查询
</el-button>
```

`@click` 表示点击事件，是下面写法的简写：

```
v-on:click="handleQuery"
```

带参数：

```
@click="loadRegistrationDetail(scope.row.registrationId)"
```

键盘事件：

```
@keyup.enter="handleQuery"
```

表示在输入框中按回车执行查询。

## 六、组件基础

### 32. 什么是组件

```
<el-button />
<el-table />
<pagination />
<dict-tag />
```

它们都是组件，可以理解成已经封装好的页面功能。

来源不同：

|组件|来源|
|---|---|
|`el-button`|Element Plus|
|`el-table`|Element Plus|
|`pagination`|若依|
|`dict-tag`|若依|
|当前页面组件|你自己编写|

### 33. `props`

父组件向子组件传递数据：

```
<dict-tag
  :options="registration_status"
  :value="registrationDetail.status"
/>
```

这里的 `options` 和 `value` 是传给 `dict-tag` 的参数。

当前阶段需要会使用现有组件的参数，暂时不要求自己设计复杂组件。

### 34. 插槽 `slot`

```
<template #default="scope">
  {{ scope.row.realName }}
</template>
```

插槽允许你决定组件某个位置显示什么内容。

表格中：

```
scope.row
```

表示当前行的数据。

例如：

```
{{ scope.row.registrationId }}
```

取得当前行的报名ID。

### 35. 具名插槽

```
<template #footer>
  <el-button>关闭</el-button>
</template>
```

表示这段内容放到组件的 `footer` 区域。

报名详情弹窗底部按钮就是这种写法。

### 36. 组件引用 `ref="..."`

模板中：

```
<el-form ref="auditFormRef">
```

脚本中：

```
const auditFormRef = ref()
```

之后可以调用组件提供的方法：

```
auditFormRef.value.validate()
```

注意这里的 `ref` 有两种相关用途：

- 脚本中的 `ref()`：创建响应式数据；
- 模板中的 `ref="auditFormRef"`：取得组件实例。

名字相同，但使用场景不同。

## 七、表单相关知识

### 37. `:model`

```
<el-form :model="auditForm">
```

告诉表单：它管理的数据对象是 `auditForm`。

### 38. `prop`

```
<el-form-item
  label="审核结果"
  prop="auditResult"
>
```

`prop` 必须和数据字段、校验规则名称对应：

```
const auditForm = ref({
  auditResult: ""
})

const auditRules = {
  auditResult: [...]
}
```

三处名字需要一致。

### 39. 表单校验规则

```
const auditRules = {
  auditResult: [
    {
      required: true,
      message: "请选择审核结果",
      trigger: "change"
    }
  ]
}
```

含义：

- `required`：必填；
- `message`：失败提示；
- `trigger`：什么时候触发校验。

常见触发方式：

- 输入框通常使用 `blur`；
- 下拉框、单选框通常使用 `change`。

### 40. `validate()`

```
auditFormRef.value.validate(valid => {
  if (!valid) {
    return
  }

  // 校验通过后提交
})
```

`valid` 是校验结果：

- `true`：通过；
- `false`：不通过。

前端校验改善操作体验，后端仍然必须校验业务数据。

### 41. 禁用状态

```
:disabled="form.status !== '0'"
```

表示不是草稿状态时，禁止编辑。

注意：前端禁用只能限制正常页面操作，不能代替后端权限和状态检查。

## 八、接口请求与异步处理

### 42. Axios请求对象

若依的 `request` 基于Axios封装：

```
return request({
  url: "/registration/manage/list",
  method: "get",
  params: registrationQuery
})
```

常用配置：

|属性|作用|
|---|---|
|`url`|接口地址|
|`method`|请求方法|
|`params`|URL查询参数|
|`data`|请求体数据|

### 43. `params` 与 `data`

GET查询通常使用：

```
params: {
  pageNum: 1,
  status: "1"
}
```

请求可能变为：

```
/list?pageNum=1&status=1
```

POST、PUT通常使用：

```
data: auditForm
```

数据放在请求体中。

### 44. Promise

接口请求不会立刻得到结果，它返回Promise。

```
getRegistrationList()
  .then(response => {
    // 请求成功
  })
  .finally(() => {
    // 无论成功失败都会执行
  })
```

需要掌握：

- `.then()`：成功后处理；
- `.catch()`：失败后处理；
- `.finally()`：最后一定执行。

### 45. 加载状态

```
listLoading.value = true

getRegistrationList()
  .finally(() => {
    listLoading.value = false
  })
```

它表达：

```
请求开始 → 显示加载
请求结束 → 关闭加载
```

建议按用途命名：

```
listLoading
detailLoading
saving
submitting
auditSubmitting
```

不要把整个页面所有操作都叫 `loading`。

### 46. `response.data`、`response.rows`、`response.total`

若依不同接口返回结构不同。

普通详情接口：

```
response.data
```

分页列表接口：

```
response.rows
response.total
```

例如：

```
{
  "code": 200,
  "rows": [],
  "total": 10
}
```

不能看到接口就一律使用 `response.data`。

## 九、Element Plus常用组件

这些属于Element Plus，不是Vue本身。

### 47. `<el-form>`

表单容器，负责组织字段和校验。

### 48. `<el-form-item>`

表单中的一项：

```
<el-form-item label="真实姓名">
```

### 49. `<el-input>`

输入框：

```
<el-input v-model="form.realName" />
```

多行输入：

```
<el-input
  v-model="form.remark"

### 50. `<el-select>` 和 `<el-option>`

下拉选择框：

```
<el-select v-model="form.applyPosition">

<el-radio-group v-model="auditForm.auditResult">

<el-button

<el-table :data="registrationList">

- `:data`：整个数据数组；

### 54. `<el-dialog>`

### 55. `<el-descriptions>`

适合显示只读详情：

```
<el-descriptions :column="2" border>
```

`column="2"` 表示通常一行显示两项。

### 56. `v-loading`

```
<div v-loading="listLoading">
```

这是Element Plus提供的加载指令。值为 `true` 时显示加载遮罩。

## 十、若依项目特有知识

### 57. `proxy.useDict()`

```
const {
  registration_status
} = proxy.useDict("registration_status")
```

根据字典类型加载字典数据。

返回的数据类似：

```
[
  { label: "草稿", value: "0" },
  { label: "待审核", value: "1" }
]
```

### 58. `<dict-tag>`

```
<dict-tag
  :options="registration_status"
  :value="form.status"
/>
```

根据字典值显示对应文字。

例如数据库保存 `"1"`，页面显示“待审核”。

### 59. `v-hasPermi`

```
v-hasPermi="['registration:manage:audit']"
```

若依的前端权限指令。当前用户没有对应权限时，会移除这个页面元素。

它负责控制按钮显示，后端的 `@PreAuthorize` 才负责接口安全。

### 60. `proxy.$modal`

```
proxy.$modal.msgSuccess("审核成功")
proxy.$modal.msgError("审核失败")
proxy.$modal.confirm("是否确认提交？")
```

这是若依封装的消息和确认框工具。

### 61. `<pagination>`

```
<pagination
  :total="total"
  v-model:page="queryParams.pageNum"
  v-model:limit="queryParams.pageSize"
  @pagination="loadRegistrationList"
/>
```

若依封装的分页组件：

- `total`：总记录数；
- `page`：当前页；
- `limit`：每页条数；
- `pagination`：切换页码后触发的事件。

## 十一、当前阶段需要掌握到什么程度

不是要求你背完上面61项。针对当前报名系统，可以分为三个层次。

第一层必须熟练：

- 看懂 `.vue` 三部分；
- 对象、数组、函数、`if`；
- `ref()` 和 `.value`；
- `v-model`、`v-if`、`v-for`；
- `:属性`、`@click`；
- `import` 和 `export`；
- `.then()` 和 `.finally()`；
- `response.data`、`rows`、`total`；
- Element Plus表单、表格、弹窗。

第二层需要能解释：

- 组件和 `props`；
- 插槽及 `scope.row`；
- 表单 `model`、`prop`、`rules` 的关系；
- 字典加载和 `dict-tag`；
- 前端按钮权限与后端接口权限的区别；
- 查询、保存、提交分别使用哪些状态变量。

第三层以后再深入：

- 自定义公共组件；
- `computed()`、`watch()`；
