### 1. `sys_user_info` 表建议补充两个字段

参照 `sys_user` 的设计模式，建议加上：

```sql|CODE_EDIT_BLOCK|E:\WorkSpace\ruoyi-archive-management\backend\sql\ry_test_01.sql
    sys_user_info_remark            varchar(500)    default null                    comment '备注',
    status                          char(1)         default '0'                     comment '报名状态（0待审核 1已通过 2已驳回）',
    del_flag                        char(1)         default '0'                     comment '删除标志（0存在 2删除）',
    primary key (sys_user_info_id),
-- ... existing code ...
```

**原因**：
- `status`：报名通常需要审核流程（待审核→通过/驳回），没有状态字段就无法管理
- `del_flag`：与若依所有表保持一致的**逻辑删除**模式，避免物理删除数据
